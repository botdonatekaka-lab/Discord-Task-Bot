# KaiX Discord Bot

A Vietnamese Discord bot for the Quần Đảo Kaia server.

## How to run

Press the **Run** button — the bot starts directly via `python run.py`.

## Required secrets

| Secret | Description |
|--------|-------------|
| `DISCORD_TOKEN` | Bot token from the Discord Developer Portal (Bot → Token) |

## Project structure

| Path | Purpose |
|------|---------|
| `bot/` | Bot source code (Python, discord.py) |
| `run.py` | Entry point |
